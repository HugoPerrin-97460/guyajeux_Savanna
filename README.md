# guyajeux_Savanna

Site vitrine one-page de **Guyajeux Saint-Paul**, bar à jeux de société à Saint-Paul (La Réunion).

- `index.html` : la page (navigation par ancres : jouer sur place, TCG, jeux de société, carte, soirées, infos)
- `style.css` : les styles
- `assets/logo.jpg` : le logo

Aucune compilation : ouvrir `index.html` dans un navigateur, ou publier le dossier tel quel (GitHub Pages, Netlify…).
